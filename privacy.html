개인정보처리방침

Shine AI · 최종 수정 2026-09-10

Shine AI는 만든 사람 한 명만 쓰는 개인용 도구입니다. 다른 사용자를 받지 않고, 가입·판매·광고가 없습니다. 아래는 그 한 사람의 구글 계정 데이터를 어떻게 다루는지에 대한 설명입니다.

1. 무엇을 읽나

범위읽는 것쓰는 것
calendar.readonly
calendar.events		 일정의 제목·시각·장소본인이 요청했을 때만 일정 등록·시간 이동
gmail.readonly 안 읽은 메일의 보낸이·제목·미리보기없음 — 메일을 보내지 않습니다
drive.metadata.readonly 파일의 제목·수정시각·링크없음

메일 본문과 문서 본문은 저장하지 않습니다. 드라이브는 파일 목록만 보고 내용은 열지 않습니다.

2. 어디에 두나

본인 소유의 맥 안에서 도는 PostgreSQL 데이터베이스에만 저장합니다. 외부 서버에 올리지 않고, 백업도 본인의 구글드라이브에만 둡니다. 접속 자격증명은 맥 키체인에 있습니다.

3. 밖으로 나가는 것

브리핑 같은 글을 만들 때 Anthropic의 Claude 모델에 다음을 보냅니다:

  • 일정 제목과 시각 · 메일의 보낸이와 제목 · 열려 있는 건의 제목
  • 메일 본문·문서 본문·첨부는 보내지 않습니다.

완성된 브리핑은 본인의 텔레그램으로 갑니다. 그 외 제3자에게 제공·판매·공유하지 않습니다. 광고·분석·추적 도구를 쓰지 않습니다.

4. 얼마나 두나

  • 주고받은 말: 180일 뒤 삭제 대상
  • 일정·메일 메타데이터: 해당 건이 닫힐 때까지
  • 실행 기록: 통계 목적으로 보관

5. 연결을 끊으려면

myaccount.google.com/permissions에서 Shine AI의 접근 권한을 삭제하면 즉시 중단됩니다. 로컬 데이터베이스를 지우면 저장된 내용도 함께 사라집니다.

6. 구글 API 제한 사용 정책

이 앱이 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy를 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.
